# Network Engineering Portfolio — Packet Tracer Labs

Welcome to my **Network Engineering Portfolio**, a collection of structured Cisco Packet Tracer labs designed to demonstrate practical networking skills, from basic switching to advanced routing and VPN configurations.

Each lab includes:
- 📌 **Topology diagrams**
- 🛠️ **Packet Tracer `.pkt` files**
- 📄 **Lab objectives, commands, and verification outputs**
- 🧭 **Skills demonstrated**

---

## 🔧 Tools & Technologies
- **Cisco Packet Tracer**
- **Micorsoft Visio** (for network diagrams)
  

---

## 🧭 Lab Progression

| Lab | Topic | Skills Demonstrated |
|-----|-------|-------------------|
| 01  | Basic Switching | Switch port configuration, VLAN basics, connectivity testing |
| 02  | VLANs & Trunking | VLAN creation, trunking, inter-VLAN routing |
| 03  | Router Basics | Router interface setup, IP addressing, ping tests |
| 04  | Static Routing | Manual routing, route verification |
| 05  | OSPF | Dynamic routing configuration, neighbor relationships |
| 06  | NAT | NAT setup for internal-to-external connectivity |
| 07  | DHCP & DNS | Configuring DHCP servers and DNS lookups |
| 08  | VPN Basics | Site-to-site VPN configuration and testing |
| 09  | Spanning Tree Protocol | Loop prevention and redundant link management |
| 10  | Advanced Project | Multi-site topology combining routing, VLANs, NAT, and VPN |
