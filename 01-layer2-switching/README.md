# Lab 01 — Layer 2 Switching

## 📌 Objective
Configure basic Layer 2 switch functionality including interface configuration, VLAN assignment, and end-to-end connectivity verification.

## 🛠 Tools & Topology
- Cisco Packet Tracer
- Access switch with multiple end devices

## 📝 Lab Tasks
1. Configure switch hostname and management settings
2. Configure access ports
3. Assign ports to VLANs
4. Verify MAC address learning
5. Test local connectivity

## 🔍 Verification Commands
```bash
show vlan brief
show mac address-table
show interfaces status
